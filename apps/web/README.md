# HelixQ Web (Milestone 1)

Search UI adapted from the Syntrak site design system (Next.js + Tailwind + raycast styles).

## Run

```bash
cd apps/web
npm install
npm run dev
```

Open http://localhost:3000

## What’s here

- Mock YouTube metadata search (client-side filter)
- Syntrak visual language kept (`globals.css`, `raycast.css`)
- Marketing pages/components removed
